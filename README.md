
# About this mod

The Prototype is a vehicle story mod for Subnautica which takes the player through new precursor facilities, new equipment and expands on the story of the Architects all while giving the player the ability to pilot and upgrade the highly advanced Prototype Submarine.

# New story

The Prototype features an all-new additional storyline to the Subnautica base game and is designed to be played on a fresh save file. The story takes the player through the highest quality precursor facilities in Subnautica modding, all to create the most advanced vehicle in the Subnautica franchise.

# Content

  -  A new submarine, The Prototype
  -  Multiple new items for progression
  -  Multiple new precursor facilities to explore
  -  Many upgrades to install on The Prototype that allow for various playstyles


<color=red>THIS MOD IS FOR THE LATEST SUBNAUTICA VERSION ONLY/color>

# How to install

  1.  Download the mod from this mod page
  2.  Unzip the file
  3.  Place the "PrototypeSubMod" folder inside your plugins folder
  4.  Example folder structure: 

    BepInEx/plugins/PrototypeSubMod



## NOTE:
You may notice a "TerrainPatches" folder inside the main mod folder. Please do not remove this folder from the main mod folder or move the files inside to the Terrain Patcher folder. Terrain patcher works for files not inside its patches folder so this is not necessary.

# Dependencies

    - Nautilus
    - Sub Library
    - Terrain Patcher
    - Epic Structure Loader
    - Suit Library (Not to be confused with Sub Library)
